Arquitectura Django para Aprendizaje

Bienvenido a la plantilla base de Django. Este proyecto está diseñado para enseñarte el funcionamiento interno de Django paso a paso, con código comentado, separación modular en aplicaciones y preparado para ser dockerizado con PostgreSQL.

Estructura del Proyecto y Módulos

Cómo se organiza el código entre la configuración central y las aplicaciones.

⚙

Configuración Central (config/)

Contiene los ajustes globales del proyecto:

  • settings.py: Configuración central comentada línea por línea.
  • urls.py: Enrutador principal con include().
  • wsgi.py / asgi.py: Puntos de enlace con servidores web.
📦

Aplicaciones Modulares (apps/)

Cada funcionalidad vive en su propia carpeta:

  • models.py: Tablas en la base de datos (ORM).
  • views.py: Lógica de respuesta a peticiones HTTP.
  • forms.py: Formularios y validaciones de usuario.
  • urls.py: Rutas locales desacopladas.
  • admin.py: Registro visual en el panel de control.
🔒

Seguridad y Variables (.env)

Manejo profesional de credenciales:

  • .env.example: Plantilla de variables documentadas.
  • .gitignore: Protege tus contraseñas y entornos virtuales.
  • django-environ: Carga segura de configuraciones.
